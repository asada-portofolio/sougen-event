# Reality Project Organizer (RPO) — Website

Website resmi RPO, event organizer budaya pop Jepang di Makassar.
Dibangun sebagai bagian dari skripsi Informatika, Universitas Teknologi Akba Makassar,
menggunakan kerangka UCD + Heuristic Evaluation + SUS.

## Tech Stack
- Frontend: React + Vite + TypeScript (Vercel)
- Backend: Node.js + Express + TypeScript (Render/Railway)
- Database: PostgreSQL + Prisma
